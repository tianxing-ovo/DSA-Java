## 核心模块详解

### 基础数据结构

- **顺序表 (`SequenceList<T>`)**
  - **底层实现**：基于泛型数组底层实现且支持迭代器接口遍历
  - **扩缩机制**：支持满载 1.5 倍自动扩容与 1/4 容量减半缩容
  - **操作支持**：提供严格的索引越界检查与完整增删改查操作
- **单向链表 (`SinglyLinkedList<T>`)**
  - **哨兵设计**：引入哨兵头节点统一空表与非空表的插入删除边界处理
  - **功能特性**：支持头尾插法与指定索引的高效增删查操作
- **双向链表 (`DoublyLinkedList<T>`)**
  - **双向哨兵**：采用双向哨兵头尾节点消除前后继指针判空的临界条件
  - **高效操作**：支持双向遍历与高效的头尾及指定位置增删

---

### 进阶数据结构

- **并查集 (`DisjointSet`)**
  - **路径压缩**：查找根节点时触发路径压缩以大幅降低后续查找深度
  - **按秩合并**：基于树规模按秩合并有效防止树形结构退化为单链
  - **连通统计**：支持动态连通性判断与集合总数统计及树结构打印
- **布隆过滤器 (`BloomFilter<T>`)**
  - **理论建模**：基于预期元素量与目标误判率公式自动推导最优参数
  - **高效哈希**：内置 64 位散列函数拆分高低位生成双重哈希组合映射
  - **测试覆盖**：单元测试万级样本实测验证实际误判率稳定符合 1% 理论预期

### 经典排序算法

|   排序算法   | 平均时间复杂度 |   最好情况    |   最坏情况    | 空间复杂度  | 稳定性 |
|:------------:|:--------------:|:-------------:|:-------------:|:-----------:|:------:|
| **冒泡排序** |    $O(n^2)$    |    $O(n)$     |   $O(n^2)$    |   $O(1)$    |  稳定  |
| **选择排序** |    $O(n^2)$    |   $O(n^2)$    |   $O(n^2)$    |   $O(1)$    | 不稳定 |
| **插入排序** |    $O(n^2)$    |    $O(n)$     |   $O(n^2)$    |   $O(1)$    |  稳定  |
| **希尔排序** |  $O(n^{1.3})$  | $O(n \log n)$ | $O(n^{1.5})$  |   $O(1)$    | 不稳定 |
| **归并排序** | $O(n \log n)$  | $O(n \log n)$ | $O(n \log n)$ |   $O(n)$    |  稳定  |
| **快速排序** | $O(n \log n)$  | $O(n \log n)$ |   $O(n^2)$    | $O(\log n)$ | 不稳定 |

#### 简单排序

- **冒泡排序 (`BubbleSort`)**
  - **基础版本**：标准双重循环相邻元素比较与交换
  - **提前终止**：引入交换标志位若整轮无逆序对则提前退出
  - **边界优化**：记录每轮最后交换位置作为下一轮比较边界
- **选择排序 (`SelectionSort`)**
  - **算法思想**：每轮扫描未排序区间最小值交换至已排序序列尾部
- **插入排序 (`InsertionSort`)**
  - **算法思想**：将未排序元素向前扫描并插入到已排序序列合适位置
- **希尔排序 (`ShellSort`)**
  - **步长优化**：采用 Hibbard 增量序列分组跨步长插入使数组整体基本有序

#### 高级排序

- **归并排序 (`MergeSort`)**
  - **分治合并**：经典分治递归双指针合并两个有序子数组且时间复杂度稳定
- **快速排序 (`QuickSort`)**
  - **单边循环**：随机选取主元单向扫描维护小于基准值边界
  - **双边循环**：随机选取主元左右双指针相向对撞扫描减少无效移动

### 系统设计与业务实战

- **三级分类树构建 (`listWithTree`)**
  - **业务场景**：数据库平铺类目结构转为前台展示所需的树状多级嵌套数据
  - **流式递归**：利用 Java 8 Stream API 配合递归下钻高效构建多级嵌套树形结构
  - **数据集成**：结合 Jackson 库验证并输出标准树形 JSON 数据
